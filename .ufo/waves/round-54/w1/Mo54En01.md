### Row 4 (8426794e271e) — overclaim

Supported: ordinary path (`send_sig_mceerr` 305–306), deliberate non-force and blockability (302–303).

```
/*
 * Signal other processes sharing the page if they have
 * PF_MCE_EARLY set.
 * Don't use force here, it's convenient if the signal
 * can be temporarily blocked.
 */
ret = send_sig_mceerr(BUS_MCEERR_AO, (void __user *)tk->addr, addr_lsb, t);
```

Not supported: the unqualified "Other processes sharing the page are signalled". The same comment block gates the
signal on early-kill opt-in (300–301), and that gate is enforced for every collected process:
`find_early_kill_thread` (500–514) returns a task only for per-process `PF_MCE_EARLY` (505–507) or when
`sysctl_memory_failure_early_kill` is set (509–510, defined at 72/137); `task_early_kill` (528–540) applies it in
`collect_procs_anon` (562) and `collect_procs_file` (595). With the global sysctl off and no `PF_MCE_EARLY`
(this host's default state per the entry), a co-mapper is never put on the list and never signalled by this code.

### Row 5 (4fdea8d0253f) — overclaim

Supported: the log line and the SIGKILL-instead-of-SIGBUS send in that branch (470–473). Not supported: "When
unmapping the corrupted page failed" as the condition. The branch runs under `forcekill`, which is three
disjuncts, and `SIGKILL` additionally requires an unresolvable address:

- 1677–1679, `hwpoison_user_mappings`: `forcekill = folio_test_dirty(folio) || (flags & MF_MUST_KILL) || !unmap_success;`
- 467–473, `kill_procs`: only `if (tk->addr == -EFAULT)` does it print the line and `do_send_sig_info(SIGKILL, …)`;
  a task with a resolved address takes `kill_proc` (482) — the SIGBUS path — even when the unmap failed.
- 402–411, `__add_to_kill`: "Send SIGKILL if 'tk->addr == -EFAULT'".

So unmap failure is neither sufficient for SIGKILL (addressable tasks still get SIGBUS) nor necessary for the
line (`MF_MUST_KILL` callers — `unmap_and_kill` 1750, `mf_generic_kill_procs` 1808–1814, `memory_failure_pfn`
2350–2356 — and dirty folios produce the identical "because of failure to unmap corrupted page" text with the
unmap successful; `kill_procs_now` 2222 fires it for unsplit THP).

### Row 6 (4748dc4eb41e) — entailed

482–484: `else if (kill_proc(tk, pfn, flags) < 0) pr_err("%#lx: Cannot send advisory machine check signal to
%s:%d\n", …);` — a failed send gets its own dedicated error line, on top of `kill_proc`'s info-level
"Error sending signal to %s:%d: %d" (308–309). The sending line (292) prints before the send attempt, and the AO
signal can be blocked (302–303), so a sending line alone does not establish that the process received anything.
