# What a careless reader might miss (whole-page v7.2→v7.3 stripped diff)

The memory *claim region* is untouched, but the 7.3 page does contain real changes a "shifted +31"
summary would flatten away — none inside any row-9..15 key:

- `memory.pressure` is now documented **read-write**, not read-only (v7.2:1688 → v7.3:1719;
  `io.pressure` likewise flipped; `cpu.pressure` was already read-write). If a future row ever
  claims "pressure files are read-only" that claim is stale at v7.3.
- New `cpu.stat.local` file and a `cpu.stat` rewrite: the five CFS-bandwidth stats are now called
  non-hierarchical, and `usage_usec/user_usec/system_usec` now explicitly include descendants.
- `cpu.max`, `cpu.max.burst`, `cpu.idle` prose: "fair-class only" replaced by "fair-class plus a BPF
  scheduler with the cgroup_set_bandwidth/_idle callback"; the weight category text changed from
  `cgroup_set_weight` to "the corresponding cgroup_set_* callback".
- IO controller section rewritten: cfq-only weight text replaced by blk-throttle absolute limits,
  iocost (CONFIG_BLK_CGROUP_IOCOST) and BFQ weight, plus iolatency/ioprio mentions.
- io.stat delay field renamed: `delay` → `delay_nsec` (microseconds → nanoseconds) in the iolatency
  prose.
- `misc.events` key renamed: `max` → `<res>.max`.
- New `dmem.peak` (device-memory peak) row; `rdma.max` gained `index=N` disambiguation
  (`-ENOTUNIQ` on ambiguous names); new cpuset.mems thread-leader ownership note.
