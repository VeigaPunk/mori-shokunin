## Per-row

### Row 9 — 07524a78c749 — memory amounts in bytes, unaligned writes rounded up

Claim: every memory amount the block prints is a byte count, and an unaligned
write may be rounded up to a page when read back.
7.3 raw line 1225-1227 (stripped 1218-1220):
"All memory amounts are in bytes.  If a value which is not aligned to
PAGE_SIZE is written, the value may be rounded up to the closest
PAGE_SIZE multiple when read back."
Unchanged from 7.2 (line 1194). Holds.
Note: the sentence sits in the *Memory Interface Files* preamble and governs
writes to interface files; `memory.stat` itself repeats only "All memory
amounts are in bytes." (stripped 1421). The claim's "the block prints" reads
the rounding clause onto the stat block, but the doc places it on
write-then-read of memory.* files — the claim as worded ("an unaligned write
may be rounded up to a page when read back") is exactly what the doc states.

## What the v7.2 -> v7.3 page diff changes that these rows do not cover

Read of all 93 changed stripped lines; nothing inside `memory.events`,
`memory.stat`, `memory.numa_stat`, `memory.swap.*`, or the byte-unit preamble.
On or near mori observability ground:

- `memory.pressure` and `io.pressure` are now documented "read-write"
  (7.2: "read-only") — the files always accepted PSI trigger writes
  (stripped 7.3 lines ~1709, ~2002).
- `io.stat` throttle text renamed `delay` -> `delay_nsec` and the unit
  changed microseconds -> nanoseconds (stripped ~2107). Any io observer
  keyed on the old name/unit reads wrong at 7.3.
- `misc.events` field `max` renamed `<res>.max` in the doc (stripped ~2835).
- New files documented: `cpu.stat.local` (throttled_usec, local-runqueue
  view vs cpu.stat's own-limit view), `dmem.peak`.
- `cpu.stat` now says its three stats account for processes "including
  those in descendant cgroups" and the five CFS bandwidth stats are
  documented as non-hierarchical (stripped ~1078-1110).
- `cpu.max`, `cpu.max.burst`, `cpu.weight.idle` now mention BPF scheduler
  callbacks; io controller text rewritten for iocost/BFQ;
  `rdma.max` gains index=N syntax; cpuset.mems gains a
  thread-leader ownership paragraph.

The ledger's drift note names only the first two of these (pressure
read-write, delay_nsec); the rest are additional same-page drift on or near
mori ground — no claim row covers them.
