# Independent source reopen — S049–S063

**Access date:** 2026-10-21. **Scope axes:** URL/content availability; exact located text and ≤25-word limit; tier/scope/status; claimed use by an r18 knowledge note. **Overall:** the primary-source readings and most dispositions hold. Three material row issues need correction: S049's teaching/anchor mismatch, S050's unsupported `used-by`, and S060's overbroad summary of SLSA input completeness. S063's tier and anchor are weaker classification issues. This is spot-check advice, not a judgment or integration decision.

## Method and limits

I re-read `corpus/SOURCES.md:55-69`, the pertinent round-18 source reports, all three `corpus/knowledge/*-r18.md` notes, and frozen C1/C2/C3 contract inputs. I then reopened every registry URL on 2026-10-21 through the static `read` tool. The PNAS publisher URL returned HTTP 403; the listed PMC full-text alternative opened and identified the same DOI. The git-scm pages and the Python page were available; the Python page is the 3.15.0 docs. The SLSA v1.0 URLs still display a banner saying v1.2 is current; the linked in-toto `main` files are accessible and the cited README says v1.2. The RFC errata URL resolves to the verified errata record. No shell commands, VCS commands, installs, or local downloads were run; no repository file other than this report was written. A first batch of five local reads used a mistyped repository-root component and returned not-found; corrected reads succeeded.

Quotes below are from the live reads, with whitespace-delimited word counts; each is below 25 words. Repository line citations identify the registered row and the corresponding source/note reading. A formal registry-wide definition for tier letters was not found in the material reviewed, so tier comments distinguish source authority from relevance to this particular question.
