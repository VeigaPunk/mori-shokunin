## Method (commands, exit codes)

- **Transcript replica (C1).** A Python replica of the contract classifier (L31-56) ran over
  `~/.omp/agent/sessions`, walked with `followlinks=False`. It read the last 262144 bytes of
  each file and dropped the first partial line. It read only these fields: `type`, `message.role`,
  `stopReason`, `errorStatus`, `provider`, `model`, the contract-named tokens of
  `errorMessage` (`429`, `rate_limit`, `Rate limit`, `RATE_LIMITED`, `resource_exhausted`,
  `quota`, `usage limit`, `402`, `credits`, prefix `Retry budget exhausted`,
  `after N retries`, `(type=NNNN)`), and the `retryRecovery` **key set**. It printed
  counts only, never text. Completed OK.
- **Directory shape.** `find … -name '*.jsonl' | wc -l` gave 5815 (rc 0); `du -sh` gave 5.4G.
  I also took a depth split and per-day mtime counts.
- **Branch resolution.** Per repo I ran `git symbolic-ref -q HEAD`, `symbolic-ref -q
  refs/remotes/origin/HEAD`, `config --get lane.branch`, `merge-base --is-ancestor HEAD
  refs/heads/<b>`, and `log refs/heads/<b> --since=2026-10-13 --format='%cn <%ce>|%an <%ae>'`.
  That covered the fleet root plus the 21 `*-shokunin` repos. All rc 0 except one: a typo'd
  `--format=x` count (rc 128), which I re-ran correctly.
- **Probe cost.** 4 extra git calls × 22 repos took 0.069–0.076 s real (3 runs, bash `time`).
- **Versions.** `jj 0.45.1-7c41cdeb`, `git version 2.56.0`, `omp/18.12.3`. These are the same
  jj and git versions as `JjAuditMori.md:17`.

## Causal separability check

C1 is a new standalone file and touches nothing in the census. C2 edits only `mori-census.sh`.
I found no shared state between the two claims. One risk would couple them: registering C1's rc 1
as a gate in the same SKILL.md table as the census. That would make the lane "red" for C1
reasons. H7's correction (register C1 as a probe) keeps the claims separable.

## Verdict (advisory)

C1 and C2 are both buildable as contracted, but each has small contract defects that cause
harm. The ones that should block admission until corrected are:

- **C1:** H2 (seat-id collision), H1 (main sessions counted as seats) and H4 (a seat that is
  retrying is classed dead). Each is fixable with one rule.
- **C2:** K2 (no defined behaviour when the branch can't be resolved, which regresses the
  r13/r14 gates), K3 (`drift` is not a census severity) and K5 (row-A parse regression).
  Each is a one-line contract fix.
- **Not blocking:** K1 and K4 are real but latent. K4 has one live false positive
  (kengaku 6180e4f).
- **Tradeoffs for L1 to state, not fix:** H3, H6, H7, K8 and K11.
