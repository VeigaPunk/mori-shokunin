# Report presence and historical marker loss

## Findings

- **Different observation surfaces.** The r20 settlement note distinguishes census `SURFACE waves`, which observes whole-wave directory markers/age and does not read per-seat reports, from the settlement scan, which checks declared members' `Report:` trailer paths in discovered dispatch JSON (`corpus/knowledge/wave-settlement-r20.md:13-18`). The scan's `present` is a path/shape observation: regular non-symlink file, nonzero size, and not the `STATUS: started` stub. The wave-level label `settled` means every member is `present`; it does not establish correct/final report contents or accepted results (`:27-40`).

- **Historical removed-marker observation.** The two baseline rows were `aggregator-r10` and `aggregator-r10-resume`, each observed with `reg=0 disp=1 run=0 settle=0` and a `WAVE_UNSETTLED_AGE` warning. Later deletion removed their `dispatch.json` markers among 18 paths; a subsequent directory probe classified both as empty and emitted no warning row (`.ufo/waves/round-21/build/HistoryRemoved.md:43-46`; `.ufo/waves/round-21/build/HistoryTokWaves.md:5-7`). The later `pushed` receipts support cleanup accounting, but were authored by the cleanup identity and do not establish an independent per-wave settlement/disposition (`HistoryRemoved.md:48-58`). The earlier r12 account explicitly says disappearance from the unsettled set does not prove settlement and preserves the actual settlement as unknown (`.ufo/waves/round-21/build/HistoryR12.md:7-17`).

- **Comparison and boundary.** Directory marker disappearance is not a per-seat report status. Nor does a per-seat `present` or wave `settled` result prove lifecycle closure: those labels are defined by report-path presence, while the historical rows describe census marker/settle fields. Conversely, an absent report at a declared trailer path is only `missing` and does not show it was never written or that its seat is dead/failed/killed (`corpus/knowledge/wave-settlement-r20.md:29-40`). The note also records that zero discovered waves can exit 0 and discovery is JSON-only; therefore a removed dispatch record may hide an identity from a later scan rather than produce a per-seat result (`:70-83`). This last consequence is an inference from the documented discovery rule, not an observation that a current scan was run.

## Disposition and limits

The evidence reviewed supports retaining both identities as unresolved historical observations with baseline, deletion, and cleanup provenance; the round-21 contract requires acceptance to remain blocked while disposition is unknown (`.ufo/waves/round-21/contract.md:7`). Whether either wave later settled or received another qualifying independent disposition remains unknown. No lifecycle outcome is inferred. No live census or source edits were performed.
