## Novelty against the do-not-repeat list

| new | nearest prior art | why it is not that |
|---|---|---|
| P1 blockquote | J5/FG5/D4 fences, N1 comments | a blockquote is a *transparent* container: the row is rendered, not hidden — fences and comments are doc'd as fatal precisely for being readable; `>` needs a different predicate |
| P2 `<details>` | N7/D? HTML table markup | F4's `html_row` is `<t[rd]`; `<details>` is an HTML container that is not a table cell |

| P7 escaped pipe | N3 tab fenced, N4 four-space | escape instead of indentation, and unlike N4 it renders *exactly* as row text |
| P8 front matter | none | a document envelope; no markdown construct |
