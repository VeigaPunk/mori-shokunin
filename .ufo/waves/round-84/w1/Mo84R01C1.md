## 3. M24c/M24d equivalence — independent byte proof (HEAD `count-c2.py`)

```text
:217 stated, malformed, duplicates = classifications(classes)
:220 agreed = 0
:222 unclassified = [token for token in snapshot_tokens if token not in stated]
:223-225 for token in snapshot_tokens: if token not in stated: continue
:226-227 if stated[token] == "unexplainable": residual += 1
:228-229 elif stated[token] == derive(token, names): agreed += 1
:231 residual += duplicates
:241-243 met = (… and not unclassified / and residual == 0 and malformed == 0 and duplicates == 0 …
              and agreed == len(snapshot_tokens) and live_ok and retired and cell)
```

- **M24c** (delete `and not unclassified`): an unclassified token is not in `stated`, hits
  `continue` (:224-225), and can never reach `agreed += 1`; so `unclassified` non-empty ⇒
  `agreed < len(snapshot_tokens)` ⇒ met False via :243 even without the dropped conjunct.
  Equivariant for every input. **Equivalent — sound.**
- **M24d** (delete `and residual == 0`): `residual = #unexplainable-stated + duplicates`
  (:226-231). An `unexplainable`-stated token takes the `if` branch, never `agreed += 1` ⇒
  `agreed < len` ⇒ :243 fails; `duplicates > 0` ⇒ the kept `duplicates == 0` (:242) fails. The
  tail prints `residual + malformed` (:248) identically either way. **Equivalent — sound.**

Residual risk (not actionable this round): the coupling markers pin the proof's *key conjuncts*,
not the whole proof — the `continue` at :224-225 and the `if`/`elif` ordering are unpinned. A
future edit that broke the proof while keeping `agreed == len(snapshot_tokens)` ×1 would read
`equivalent` for a killable mutant. Same single-marker design as r83's A1.
