# C1 independent receipt recount

**Scope:** Read-only falsification of C1 before/after retained `run-manifest.json` records and the retained after-run stdout/stderr. No production files, live transcripts, gate/tool runs, tests, selftests, or VCS operations were used. Only this report was added; no tool was installed or updated.

## Finding

No inconsistency was found in the attacked C1 measurement evidence. Independent case recount gives **before: capability_absent 54 + mismatched 0 = 54; after: capability_absent 0 + mismatched 0 = 0; exact after matches: 54/54**, with identical before/after case-ID sets. Each manifest's case statuses reconcile to its summary.

I independently parsed all 54 retained after stdout/stderr pairs and checked them against the per-case digests. For the **51 cases with class totals and a seat list**, every observed total matched a fresh count from the output seats (excluding `kind: main`); the per-case totals also matched the manifest's `observed.totals`. Summed across those repeated fixture-case outputs, `observed / seat-list recount` was: aborted 7/7, completed 27/27, dead_error_other 3/3, dead_quota 12/12, dead_rate_limit 19/19, error_unsettled 4/4, incomplete 6/6, unavailable 12/12. Three matching setup cases (`max_files_exceeded`, `missing_dir_rc2`, `prefix_filter_no_match`) intentionally have no output class totals or seat list and were not included in that class sum.

The 132 manifest fixture-input-map entries are identical within each run and across before/after; all 81 declared fixture pins are reported verified, with no `inputs_changed`. Per-case pack before/after hashes are equal. `expected.json` SHA-256 is `b684c63bf3cebe70f24d3d02f3f0df4f63aad3f547a365a3ca1864f5f57cb01f`; both gate digests and the after tool digest match `PINNED_INPUTS.json`.

The timestamped `count-c1.json` receipt (`2026-10-20T16:35:15.312598-03:00` through `2026-10-20T16:35:15.315322-03:00`) passed runtime UTC future-time checks and predates the pinned-input observation (`2026-10-20T16:35:35.191504-03:00`). The two run manifests contain no timestamp fields, so their dates cannot be independently established from those manifests themselves.
