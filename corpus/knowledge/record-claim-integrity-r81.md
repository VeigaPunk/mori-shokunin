# Record claim integrity: a record cell is a claim until its own command reproduces it (round 81)

## K1 — What the source grounds

stat(2) puts the file type in `st_mode` (`:235-236`, in its discussion of lstat's required fields) and dispatches one `S_IFMT` switch whose cases include `S_IFDIR` (directory) and `S_IFREG` (regular file) (`:317`, `:320`, `:323`). The page states no normative "a directory is not a regular file" sentence; the distinctness is shown by the switch, so the admitted scope is the type-bit distinction itself. Applied to a record: a naming assertion ("`tools/pkg.py` is an instrument") is a claim about a path; the path's type bits are what the bytes carry, and a presence test that never reads the type does not establish that distinction.
